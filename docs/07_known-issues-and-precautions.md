# 07. 현재 데이터의 알려진 한계와 주의사항 (수업 사용 버전)

- 버전: **v0.2.0** (1000명 풀스케일 — 옵션 B 머지 전략)
- 합성일: 2026-05-26
- 최종 갱신: 2026-05-26
- 평가: 외부 sub-agent 8/8 PASS (rubric Section 5 PASS 기준 완전 충족)

본 문서는 **현재 배포된 100명 v2 시범 데이터** (`data/pilot-100-v2/`) 에 대한 알려진 한계·주의사항·DO/DON'T를 정리한다. 학생과 학생의 LLM 보조자가 분석 시 항상 이 문서를 참조해야 한다.

> **이 문서를 읽는 LLM에게**: 학생이 본 데이터로 분석을 요청하면 본 문서 Section 3 (DON'T) 위반 여부를 먼저 점검하고, 위반 시 학생에게 알린 뒤 Section 2 (DO) 범위 내에서만 답하라.

## 1. 현재 데이터의 알려진 한계

### 1-1. 표본 규모 — 1000명 풀스케일 (v0.2.0)

- 1000명 풀스케일 데이터 (`data/pilot-1000/`) — 500명 × 2 batch 머지 (옵션 B 전략)
- 사용 패턴 7종 모두 등장 (87~202명)
- 9유형 사용자 분류 9종 모두 등장 (각 100명 내외)
- 9유형 × 사용 패턴 63 cell 모두 ≥7명 (외부 평가에서 확인)
- 80대 50명·90대 18명 — 고령군 분석도 100명 시범보다 안정
- 100명 v2 (`data/pilot-100-v2/`)는 호환성 위해 유지

### 1-2. 평가 상태 — 3차 외부 평가 8/8 PASS

본 데이터는 다음 검증 단계를 거쳤다:

1. **1차 외부 sub-agent 평가 (100명)**: CONDITIONAL PASS, 결함 7건 발견
2. **결함 7건 코드 fix** → 100명 v2 재합성
3. **2차 외부 평가 (100명 v2)**: PASS, 신규 regression 1건 발견 (PHQ-9 0~27 범위)
4. **Fix 8 (PHQ-9 0~27 clip) 적용** → 500명 × 2 batch 합성 후 머지 (1000명)
5. **3차 외부 평가 (1000명)**: **8/8 PASS** — A·D·G FAIL 0, 핵심 가설 E 5/5 강한 단조

→ 데이터의 분석 가치는 외부 평가에서 정식 검증됨. 단 합성 데이터 본질적 한계는 그대로 (Section 1-4 참조).

### 1-3. 1차 평가 결함과 해결 상태

| # | 결함 | 1차 (fix 전) | v2 (현재) | 상태 |
|---|---|---|---|---|
| 1 | WHODAS 0~60 범위 위반 | 11건 | 0건 | 해결 |
| 2 | dialogue_turn_id 페어 없음 | 100% 단일 row | 75% 페어 / 25% 단독 | 해결 |
| 3 | trial_drop 사용자 누락 | 15/16명 0 event | 0/16명 누락 | 해결 |
| 4 | 야간 0~6시 active 이벤트 과다 | 94% | 44% | 개선·일부 잔존 |
| 5 | MMAS 평균 (의도 14~18) | 9.17 | 14.9 | 해결 |
| 6 | STT 변형 비율 (의도 10~30%) | 9% | 13.0% | 해결 |
| 7 | 효돌 발화 평균 (의도 30~40자) | 52.6자 | 43.1자 | 개선·약간 초과 |
| 8 | PHQ-9 0~27 범위 (Q10 기능손상 별도) | 1건 위반 | **0건** (post-fix 적용) | 해결 |

**v0.2.0 (1000명) 신규 명시 사항**:

| # | 항목 | 결과 | 상태 |
|---|---|---|---|
| **9** | **STT 변형 비율 — 분모 정의 명확화** | 분모에 따라 다름 (아래 참조) | ✅ 합성 모델 정상 동작, 문서 명시로 해결 |
| 10 | dialogue_turn_id hash 충돌 | 3.67M event 중 77건 (0.002%) | 무시 가능 |

#### STT 변형 비율 — 두 분모의 차이

3차 외부 평가에서 STT 변형 비율을 약 45%로 보고했는데, 이는 **분모 정의의 차이**에서 비롯된다. 합성 모델 오류 아님.

| 분모 | 분자 (변형 박힌 turn) | 비율 | 학생 분석 시 권장 |
|---|---:|---:|---|
| **전체 senior 발화** (612,308) | 78,142 | **12.76%** | ✅ 학생 분석 시 이 분모 사용 권장 — 직관적·해석 쉬움 |
| has_target (효돌 키워드 보유 turn, 81,050) | 35,917 | 44.3% | △ 합성 모델 디버깅·내부 평가용 |

**의도**: 전체 senior 발화 분모 기준 10~30%. **현재 12.76%로 의도 범위 정상**.

학생 분석 시 SQL 예시:
```sql
-- 권장 — 전체 senior 발화 분모
SELECT
  ROUND(100.0 *
    COUNT(*) FILTER (WHERE dialogue_text LIKE '%효도리%' OR dialogue_text LIKE '%효소리%' OR dialogue_text LIKE '%효들이%') /
    COUNT(*), 2) AS stt_variant_pct
FROM behavior_log
WHERE event_type = 'dialogue' AND dialogue_speaker = 'senior';
```

→ **메타 교훈**: 비율 지표 보고 시 항상 분모를 명시. 같은 데이터·같은 합성 모델이라도 분모를 다르게 잡으면 12.76% vs 44.3%로 정반대 해석이 나온다. 학생 보고서에도 이 원칙 적용 권장.

### 1-4. 합성 데이터 본질적 한계 (재강조)

- 발견되는 모든 패턴은 합성 모델이 박은 것의 재발견
- 합성 모델에 없는 패턴은 발견될 수 없음
- 통계 검정 p-value는 의미 없음
- 효돌 사용자 모집단 추론·인과 추론 모두 불가

상세 → `docs/05_limitations-and-ethics.md`

## 2. DO — 본 데이터에서 가능한 분석

### 2-1. 분포 탐색
- 연령·성별·지역별 인구통계
- 사용 패턴 7종 분포
- 9유형 사용자 분류 분포
- 베이스라인 설문 점수 분포 (히스토그램, boxplot)

### 2-2. 그룹 간 비교 (탐색적)
- 연령대별 사용 강도 차이
- 사용 패턴별 사전·사후 설문 점수 변화
- 9유형 사용자 분류별 만족도 차이

### 2-3. 시계열 패턴
- 일별·시간대별 활동 패턴
- 사용 패턴별 90일 시계열 (loyal_heavy·growing·declining 명확하게 박힘)
- 일중 peak (오전·점심·오후·저녁)

### 2-4. ★ 인지 측정 페어링 (본 데이터셋의 핵심 분석축)
- prompt-response 페어 응답률·딜레이 분석
- 연령·우울·기능제약과 응답 딜레이 관계
- prompt_type별 응답 패턴

### 2-5. 대화 분석
- 효돌·노인 발화 패턴
- `dialogue_turn_id`로 turn 단위 분석
- STT 인식 오류 패턴 (효도리/효소리 등 변형)

### 2-6. 설문 사전·사후 변화
- 사용 패턴별 GDS·PHQ-9·UCLA 변화량 비교
- 사용 강도와 변화량 상관

## 3. DON'T — 본 데이터에서 하면 안 되는 분석

| ❌ 안티패턴 | 이유 |
|---|---|
| "효돌이 우울을 감소시킨다" 같은 인과 추론 결론 | 합성 데이터 — 인과 추론 불가 |
| t-test·ANOVA p-value 보고로 효과성 입증 | p-value 의미 없음 |
| "한국 노인 60+의 X%가 ~다" 같은 모집단 추론 | 100명 시범 — 일반화 불가 |
| 개별 user_id를 보고서에 노출 | 집계·군집 단위로만 보고 |
| 본 데이터의 분석 결과를 효돌 서비스 실제 효과로 외부 발표 | 합성 데이터 — 실제 효과 입증 불가 |
| 임상·정책 결정 근거로 사용 | 부적합 |
| 80대 5명·90대 2명 등 작은 군집의 세부 통계 | 표본 너무 작음 |
| 9유형 × 사용 패턴 7종의 63 cell cross-tab | cell당 1~2명 — 분산 너무 큼 |
| 데이터 파일을 외부 공개 GitHub/SNS/블로그에 업로드 | 라이센스 CC BY-NC-SA 4.0, 수업 내 사용만 |

## 4. 분석 우선 권장 순서 (수업용)

1. **분포 확인** — profile 한 테이블로 시작 (SQL 기초)
2. **시계열 탐색** — behavior_log의 일별·시간대별 패턴
3. **★ 인지 측정 페어링** — 본 데이터셋의 핵심 신규 분석축
4. **사전·사후 변화** — 사용 패턴별 GDS·PHQ-9·UCLA 비교
5. **대화 분석** — turn 단위·STT 오류 패턴

각 단계에서 합성 데이터 본질을 잊지 말 것.

상세 SQL 패턴 → `docs/04_analysis-guide.md`

## 6. 1000명 풀스케일 데이터셋이 나오면

본 100명 v2는 시범 데이터다. 1000명 풀스케일에서는:

- 작은 군집의 통계적 안정성 확보 (E3 가설 — GDS↑→응답률↓ 등이 더 강하게 박힐 예정)

→ 1000명 데이터셋 출시 시 학생 분석을 재실행하여 패턴 일관성을 확인하는 것을 권장.
